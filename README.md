<h1 align="center">waste-app (React Native / Expo)</h1>
<p align="center">
  A waste-detection starter app built with React Native and Expo.  
  Runs on Android, iOS, and web, with Fast Refresh &amp; debugging.
</p>

<hr/>
gi
<h2>📥 Prerequisites</h2>
<ul>
  <li><strong>Node.js</strong> (LTS ≥ 16.x)</li>
  <li><strong>npm</strong> or <strong>Yarn</strong></li>
  <li><strong>Expo Go</strong> on your mobile device</li>
  <li>For web: a modern browser (Chrome / Firefox / Safari)</li>
  <li>(Optional) Android Studio or Xcode for simulators</li>
</ul>

<hr/>

<h2>🚀 Getting Started</h2>
<ol>
  <li>
    <strong>Clone the repo</strong><br/>
    <code>git clone https://github.com/Utpam/KHP-01.git<br/>cd KHP-01</code>
  </li>
  <li>
    <strong>Install dependencies</strong><br/>
    <code>npm install<br/># or<br/>yarn</code>
  </li>
  <li>
    (Optional) <strong>Clear Metro cache</strong><br/>
    <code>npx expo start --clear</code>
  </li>
</ol>

<hr/>

<h2>▶️ Running the App</h2>

<h3>1. On Android / iOS device</h3>
<ol>
  <li>Start Metro:<br/><code>npx expo start</code></li>
  <li>
    In the terminal UI, press:  
    <ul>
      <li><code>a</code> for Android emulator</li>
      <li><code>i</code> for iOS simulator (macOS only)</li>
    </ul>
  </li>
  <li>Or open <strong>Expo Go</strong> on your phone and scan the QR code.</li>
</ol>

<h3>2. On Web</h3>
<ol>
  <li><code>npx expo start --web</code></li>
  <li>Visit <code>http://localhost:19006</code> in your browser.</li>
</ol>

<hr/>

<h2>🐞 Debugging &amp; Development</h2>
<ul>
  <li><strong>Fast Refresh:</strong> Save any <code>.js/.tsx</code>, the app reloads changed modules.</li>
  <li><strong>Dev Menu:</strong> Shake device or press <code>d</code> in the terminal.</li>
  <li><strong>Element Inspector:</strong> From Dev Menu select “Toggle Element Inspector.”</li>
  <li><strong>Remote JS Debugging:</strong> In Dev Menu choose “Debug Remote JS” (opens Chrome DevTools).</li>
  <li>
    <strong>Clear Metro cache:</strong><br/>
    <code>npx expo start --clear</code>
  </li>
</ul>
